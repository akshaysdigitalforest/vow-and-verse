# Vow & Verse — Invitation Studio

A wedding invitation studio with a static HTML/CSS/JavaScript editor on GitHub Pages and an API on Google Cloud Run. Invitations, uploaded photos, and RSVP replies use Firestore and a private Cloud Storage bucket.

## Included

- 20 selectable wedding invitation themes with free/signature labels and style filters.
- Live, scrollable preview of a multi-section guest invitation website: cover, countdown, story, schedule, venue directions, optional hotel directions, and RSVP.
- Add up to 12 schedule events, each with a name, time, and short punch line.
- Editor for names, date, event details, cover/gallery images, an optional looping cover video, RSVP contact, hotel name and Google Maps place link, and dress note.
- Browser-local draft autosave, unique guest link, downloadable guest-link QR code, and standalone HTML website download.
- Cloud-hosted invitation drafts and guest responses, plus private image uploads. Cover videos use a direct HTTPS video link hosted by the creator.
- Responsive storefront, example packages, and configurable external checkout links.

## Personalize the product

1. Open `script.js` and edit `storeSettings` to set your real prices and checkout URLs.
2. Create digital products/payment links with your chosen checkout provider. Put the relevant URLs in `checkoutLinks.single` and `checkoutLinks.custom`.
3. Replace the example package text/prices in `index.html` so they match what you actually deliver.
4. Update branding, support contact, privacy notice, and terms before selling.
5. Add your own licensed fonts and photos if you want the project to avoid third-party image/font dependencies.

## Publish on GitHub Pages

1. Create a GitHub repository and upload the project files to its root.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Use the Pages URL shown in the repository settings.

## Selling limitations to plan for

This beta uses a Google Cloud backend. Guest links contain a random invitation ID; details are stored in Firestore, photos stay in a private Cloud Storage bucket, and guest replies are saved for the creator to view. QR downloads point to the same guest link. Venue/address search and the optional hotel Google Maps share link appear as separate guest-facing directions. Payment verification, order fulfillment, and paid access still need server-side services.

GitHub Pages hosts the builder and guest-facing invitations. The unique guest URL is generated by the builder; downloaded HTML sites can also be hosted elsewhere. Custom domains need domain and DNS setup.
